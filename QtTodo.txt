Qt / Linux Conversion TODO
==========================

Files already converted
-----------------------
  MainWindowQt.hpp / src/GUI/Linux/MainWindowQt.cpp
    - Top-level QMainWindow; owns QTabWidget, menus, config, auto-load, orders export.

  ReportsTabContentQt.hpp / src/GUI/Linux/ReportsTabContentQt.cpp
    - "Loaded Reports" tab: QListWidget + QSplitter detail pane (faction, month,
      found/visited regions), context menu (Load / Remove), Clear button.
    - Wired into MainWindowQt::deferredInit() and refreshAllTabs().

Files that do NOT need a Qt equivalent
---------------------------------------
  WinGuiUtils.hpp / WinGuiUtils.cpp
    - Win32 GetWindowText wrapper. Qt widgets expose .text() / .toPlainText()
      directly; no helper needed.

  WinTabView.hpp / WinTabView.cpp
    - Win32 WC_TABCONTROL wrapper. Fully replaced by QTabWidget in MainWindowQt.

  MainWindowWin.hpp / MainWindowWin.cpp
    - Windows-only main window; superseded by MainWindowQt.

  ReportsTabContent.hpp / ReportsTabContent.cpp
    - Windows version of the reports tab; superseded by ReportsTabContentQt.

  ControlIds.hpp
    - Win32 child-window numeric IDs. Qt widgets are identified by pointer,
      not integer ID; no equivalent needed.

  ResourceIds.hpp
    - Win32 RCDATA / icon resource IDs. Qt uses .qrc files; handle if/when
      an application icon or embedded resource is needed on Linux.

  AtlantisMajordomo.rc / AtlantisMajordomo.ico
    - Windows resource script and icon. Replace with a .qrc entry if a Linux
      app icon is required.

  OrdersEditorUtils.hpp / OrdersEditorUtils.cpp
    - Win32 context-menu + HWND edit-control helpers used exclusively by
      MapTabContent. Port inline into MapTabContentQt when that tab is
      implemented; no stand-alone Qt file is necessary.
