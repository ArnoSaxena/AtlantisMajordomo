  ReportsTabContent.hpp / ReportsTabContent.cpp
    - Windows version of the reports tab; superseded by ReportsTabContentQt.

      not integer ID; no equivalent needed.

  ResourceIds.hpp
    - Win32 RCDATA / icon resource IDs. Qt uses .qrc files; handle if/when
      an application icon or embedded resource is needed on Linux.

  AtlantisMajordomo.rc / AtlantisMajordomo.ico
    - Windows resource script and icon. Replace with a .qrc entry if a Linux
      app icon is required.

  OrdersEditorUtils.hpp / OrdersEditorUtils.cpp
    - Win32 context-menu + HWND edit-control helpers.  After the MapTabContent
      split, all actual usage is in MapTabContent_Orders.cpp only
      (ordersEditorSubclassProc: showOrdersEditorMenu, insertFormBlockAtEnd,
      kOrders*Cmd constants).  The other split files include the header via the
      shared preamble but do not call anything in it.
    - Port inline into sub-step 7.4 (MapTabContentQt_Orders.cpp): replace
      showOrdersEditorMenu with QPlainTextEdit::createStandardContextMenu()
      extended with a "Form New Unit" QAction, and replace insertFormBlockAtEnd
      with a plain QString insertion.  No stand-alone Qt file is necessary.
